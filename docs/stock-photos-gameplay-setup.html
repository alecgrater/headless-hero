Stock Photos & Gameplay Setup Guide

Step-by-step instructions to get real stock photos (Pexels) and real gameplay clips (Twitch VODs) working in Headless Hero.

A Stock Photos (Pexels)

What you need

A free Pexels API key. No credit card required. 200 requests/month on the free plan.

Step 1: Get a Pexels API Key

  1. Go to https://www.pexels.com/api/
  2. Click "Get Started" (or sign in if you already have an account)
  3. Fill out the form — project description can be anything (e.g., "Video content creation tool")
  4. Copy the API key they give you

Step 2: Add the Key to Headless Hero

  1. Open Headless Hero
  2. Go to Settings (gear icon, top-right)
  3. Scroll to the API Keys section
  4. Find "Pexels" and paste your key
  5. Click Save

Step 3: Enable Stock Photos During Script Generation

  1. Start a new project and get to the Script Generation page
  2. Before generating, expand the "Media Sources" section (click the header to expand)
  3. Check the "Stock photos" checkbox (it only appears if your Pexels key is configured)
  4. Generate the script

Step 4: Verify It Works

  1. After script generation, go to the Timeline
  2. Look at the scene properties — some scenes should show media_source: stock_photo
  3. Click "Generate All Images"
  4. Watch the backend terminal — you should see lines like:
INFO  [PEXELS] scene abc123 — query: Golden Gate Bridge at sunset

If you instead see [GEMINI] for every scene, the media_source was not set correctly on those scenes.

✓ How to confirm it's a real photo

Look at the generated image file. Open data/projects/{script_id}/images/{scene_id}.prompt — if it says something like Golden Gate Bridge at sunset (a short search query) rather than a long style-guide prompt, it came from Pexels. The image itself will be a real photograph, not an AI illustration.

B Gameplay Clips (Twitch VODs)

What you need

A Twitch application with Client ID and Client Secret. Free, but requires a Twitch account.

Step 1: Create a Twitch Application

  1. Go to https://dev.twitch.tv/console/apps
  2. Log in with your Twitch account (create one if needed — free)
  3. Click "Register Your Application"
  4. Fill in:
    • Name: anything (e.g., "Headless Hero")
    • OAuth Redirect URLs: http://localhost
    • Category: "Application Integration"
  5. Click "Create"
  6. Click "Manage" on your new app
  7. Copy the Client ID
  8. Click "New Secret" and copy the Client Secret

Step 2: Add the Keys to Headless Hero

  1. Open Headless Hero → Settings → API Keys
  2. Find "Twitch Client ID" and paste it
  3. Find "Twitch Client Secret" and paste it
  4. Click Save

Step 3: Enable Gameplay During Script Generation

  1. Start a new project — choose a topic that involves video games (e.g., "Top 5 Most Influential Games of All Time")
  2. Before generating the script, expand "Media Sources"
  3. Check the "Gameplay clips" checkbox (only visible if Twitch keys are configured)
  4. Generate the script — Claude will assign media_source: gameplay_video to scenes that discuss specific games

Step 4: Verify It Works

  1. In the Timeline, scenes with gameplay assigned will show a game name
  2. Click "Generate All Images"
  3. Watch the backend terminal:
INFO  [TWITCH] scene xyz789 — game: Minecraft, duration: 5.0s

Gameplay clips are saved as .mp4 files in data/projects/{script_id}/clips/

✓ How to confirm it's real gameplay

Check data/projects/{script_id}/clips/{scene_id}.mp4 — it should be an actual video file (playable in QuickTime/VLC). It's a segment from a Twitch VOD, not a generated image.

C Run the Automated Test

There's a test suite that proves the routing works without needing real API keys:

cd backend && uv run pytest tests/test_media_source_dispatch.py -v

This mocks external APIs and verifies:

  1. media_source: "ai" → calls Gemini (not Pexels, not Twitch)
  2. media_source: "stock_photo" → calls Pexels (not Gemini)
  3. media_source: "gameplay_video" → calls Twitch (not Gemini, not Pexels)
  4. Mixed scenes route each to the correct provider
  5. Missing API keys surface errors (not silent fallback to AI)

D Troubleshooting

⚠ Checkboxes don't appear in Media Sources

The "Gameplay clips" checkbox only shows when Twitch keys are configured. "Stock photos" only shows when the Pexels key is set. Go to Settings → API Keys and make sure the keys are saved (green checkmark next to each).

⚠ All scenes still show [GEMINI] in logs

This means Claude didn't assign stock_photo or gameplay_video to any scenes. This can happen if:

  1. You forgot to check the checkbox before generating the script
  2. The topic doesn't naturally lend itself to real photos/gameplay — try a topic with real-world subjects (stock photos) or specific game names (gameplay)
  3. You can manually change a scene's media_source in the Properties Panel (right side of timeline) to force it

⚠ "PEXELS_API_KEY not configured" error

The key was not found in the environment. Make sure you saved it in Settings → API Keys. Restart the backend after saving (npm run dev again).

⚠ "Game not found on Twitch" error

The game name Claude assigned doesn't match Twitch's catalog exactly. You can edit the gameplay_game_override field on the scene in the Properties Panel to the exact game title as it appears on Twitch (e.g., "Grand Theft Auto V" not "GTA 5").

⚠ "No VODs found for game" error

The game exists on Twitch but no English-language archived streams (VODs) are available. This is rare for popular games but can happen for very niche titles. Try a more popular game name.
