Title Card Compositing: Two Approaches

How should the composite image + zoom video be constructed?

A

Pillow Composite + FFmpeg Zoompan

Recommended. Generate one static composite PNG with Pillow (circles, title, labels, colors). Then use FFmpeg's zoompan filter to animate the zoom from full card → target circle during rendering.

Pros

  • Clean separation: Pillow handles layout/design, FFmpeg handles animation
  • Composite PNG doubles as YouTube thumbnail (no extra step)
  • Zoom target coordinates are deterministic from grid layout math
  • Pillow gives full control over fonts, anti-aliasing, circle masking

Cons

  • Adds Pillow as a new dependency
  • Two tools involved (Pillow + FFmpeg) instead of one
B

Pure FFmpeg (Overlay + Crop + Zoompan)

Use FFmpeg's overlay, crop, and drawtext filters to compose the grid and animate the zoom in a single pipeline.

Pros

  • No new dependency — everything stays in FFmpeg
  • Single tool for both composition and animation

Cons

  • FFmpeg filter graphs for 10+ overlays + circle masks + text styling get extremely complex
  • Limited font styling (no easy bold+highlight word coloring)
  • Circle masking in FFmpeg requires complex alpha channel manipulation
  • Need separate step to extract a static thumbnail anyway
  • Hard to debug and maintain

Approach A Data Flow

Script Generation (Claude)
  → segments with: name, circle_color, condensed_title, highlight_word

Image Generation (existing pipeline)
  → one AI image per segment (square, will be circle-cropped)

Pillow Compositing (NEW)
  → circle-crop each image
  → place on colored circle backgrounds in grid
  → render title text with highlight word
  → render segment labels
  → output: composite.png (1920×1080)
  → also saved as thumbnail

FFmpeg Rendering (modified)
  → title card scene: zoompan from full card → target circle
  → zoom coordinates calculated from grid position
  → duration = narration audio length
